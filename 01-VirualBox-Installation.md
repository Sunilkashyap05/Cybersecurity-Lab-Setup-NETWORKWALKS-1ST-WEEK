## 📌 1. Introduction

Oracle VM VirtualBox is a free and open-source virtualization software. It allows users to run multiple operating systems on one physical computer.

**Purpose:** To create a controlled cybersecurity lab environment for learning ethical hacking and penetration testing.

## 💻 2. System Requirements

Before installing VirtualBox, check these requirements:

- Windows 10 or Windows 11
- Minimum 8 GB RAM recommended
- At least 20 GB free disk space
- 64-bit processor
- Hardware virtualization enabled

## 📥 3. Download VirtualBox

1. Open the official VirtualBox website.
2. Navigate to Downloads.
3. Select Windows Hosts.
4. Download the installer.

Official Website: https://www.virtualbox.org/wiki/Downloads

## ⚙️ 4. Installation Wizard

1. Open the downloaded installer.
2. Click Next.
3. Review the installation options.
4. Continue with the setup wizard.

![Installation Wizard](screenshots/Installation-Wizard.png)

## 🛠️ 5. Custom Setup

1. Select the installation location.
2. Review the available features.
3. Keep the default options unless you need to change them.
4. Click Next.

![Setup Custom](screenshots/Setup-Custom.png)

## 🌐 6. Network Warning

During installation, VirtualBox may temporarily reset network connections.

1. Read the warning.
2. Save your work.
3. Click Yes to continue if you are ready.

![Network Warning](screenshots/Network-Warning.png)

## ⏳ 7. Installation Progress

Wait while VirtualBox installs the required components.

![Installation Progress](screenshots/Installation-Progress.png)

## ✅ 8. Installation Complete

1. Click Finish.
2. Open Oracle VM VirtualBox.
3. Verify that VirtualBox Manager launches successfully.

![Installation Complete](screenshots/Installation-Complete.png)

## 🔍 9. Verification

Open VirtualBox Manager and check the installed version using Help → About VirtualBox.
